# Te quiero ❤

Un corazón formado por "te quiero" en 20 idiomas, hecho con HTML, CSS y JavaScript (canvas).

- `index.html`: la página
- `style.css`: estilos (fondo negro, letras rosa)
- `script.js`: la animación. Arriba del todo está `CONFIG`, donde puedes cambiar el mensaje final, los colores y la velocidad.

Toca o haz clic en la pantalla para repetir la animación.
